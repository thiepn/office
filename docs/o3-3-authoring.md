# O3.3 professional authoring
Additive rich envelope v1 layout and closed typography attributes. No storage engine, database, record ID, revision or CAS change. Import creates a new ID only after JSON envelope validation, ProseMirror schema check, round-trip attribute check and explicit confirmation. Exchange exports the current valid structured draft and original Markdown, not a full history backup. Page width is a continuous canvas; browser printing uses selected paper size, orientation and margins. No simulated page breaks, no DOCX, no guaranteed PDF fidelity. Lazy-load the minified bundle outside the library; no new dependencies. Preserve all prior tests; qualify new tests and actual printed output before release. No deployment or migration.
