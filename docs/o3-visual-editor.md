# O3.1 visual authoring foundation

O2 records remain the authority: schemaVersion 1, original ID, Markdown body, revision, bounded history and transactional CAS. No database version or migration changes. The existing source editor remains the default and escape hatch. Opening visual mode must round-trip the existing source exactly before revealing the canvas. Unsupported syntax stays in Markdown; no automatic normalization of pre-existing documents.

The initial visual canvas supports single-line paragraphs, headings 1–3, simple bold/italic/inline code display, flat ordered/unordered lists, simple quotations and browser-native undo/redo. Paragraphs are separated by blank lines. No HTML is parsed from Markdown; DOM nodes are constructed with textContent. Paste is plain-text only, and drops are blocked. Unsupported visual DOM or Markdown disables persistence of that draft, retains the visual contents and offers explicit plain-text recovery export or confirmed discard. Valid edits flow through the existing O2 autosave path and CAS.

This is an incremental prototype, not a complete Word replacement. Browser-native execCommand is deprecated and must be qualified across the three browser engines; a mature structured editor with a deterministic document schema is the target before claiming professional-grade authoring. Nested formatting, arbitrary Markdown, tables, links, images, page breaks, pagination, DOCX and academic typesetting are intentionally not yet supported visually. Existing Markdown can still store these as source. The paper canvas is continuous, not an A4 pagination engine. No runtime dependency or deployment change.

Acceptance: full O2 regression suite, exact-source round-trip with no extra revision, safe formatting persistence, unsupported-source fallback, invalid-draft recovery, cross-tab CAS, keyboard and mobile checks. O3 follow-on: replace browser command reliance with a structured editor transaction model; implement lossless schema/Markdown compatibility and tables, links, accessible toolbar state, layout and export gates.
