## Contract
Additive private manifest RPC derives owner from existing authorize() and checks live session, Office client, read grant, deletion state. Public invoker wrapper, private definer with empty search path, explicit execution grants. Manifest is bounded by existing 100-document quota, contains only id and revision including trashed records. No timestamp cursor or additional table. Compare local remoteRevision against manifest; download only unknown/newer records; confirm missing records with read RPC; never silently delete or overwrite pending edits. A new cycle can resume after interruption; push uses existing immutable operation IDs and idempotency receipts. Same-revision divergence is checked when a full record is read; manifest assumes normal server CAS monotonicity, not arbitrary external database rewrites.
## Conflict resolution
Library displays both observed versions. Re-read cloud record before confirmation; changed remote requires explicit refresh/review. Resolution transaction compares complete expected local record/queue/conflict and archives local snapshot, pending operations and observed remote before replacing active record. Keep cloud; fork local with new ID and retained original history; or apply local as new revision atop reviewed cloud CAS (blocked if it would downgrade or change immutable structured source). If remote absent, explicit local retry creates with expected null. Reviewed snapshot matching is enforced in the storage transaction, not just the UI; previously observed remote snapshots are retained without silent truncation. Local archive is exported, not uploaded; revision histories of divergent branches cannot both be the canonical linear history, so archive preserves discarded branch. Existing records retain IDs; fork is explicit. Account editor saves also compare expected snapshot to avoid revision-number ABA after conflict resolution. IDB upgrade adds owner-scoped archives store without deleting old records; guest DB unchanged. Recovery archive size/retention management remains future work.

Python stdlib gateway executes fixed RPC allowlist as authenticated under synthetic session claims; untrusted values hex-encoded, no hosted credentials, two distinct sessions for same owner and another owner. Browser contexts have separate IndexedDB/storage, shared real database. Shared SDK runs synthetic token/user endpoints, actual SQL RPCs via gateway, external network blocked in browser. Test loses a commit acknowledgement, independently observes the committed operation from device B before retry, checks immutable retry across reload, discovery and owner isolation, concurrent edits, durable conflict fork and archive. This does not test hosted PostgREST/JWT enforcement or physical devices. Production stays disabled. Manual sync only, no background polling of remote documents; no automatic destructive conflict merge. Review server grammar/lifecycle/retention and deployment gates before activation. CI pending.
