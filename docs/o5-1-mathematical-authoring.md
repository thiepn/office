# O5.1 — Mathematical authoring foundation
Base: qualified Office main 4314b91b57d16b5512ba943ae0427e9337ffa6e5 (195/195). Separate branch. No production activation.
## Authoring
Explicitly upgrade a Markdown document to structured editing before using Insert inline equation / Insert display equation. Both open a native modal with raw LaTeX input, bounded live MathML preview, cancel and apply. Display equations offer automatic numbering; select an equation and use Edit selected equation to change source or numbering. Numbering follows document order, excludes unnumbered display and inline nodes, and is derived by ProseMirror decorations rather than persisted or accepted from an imported file. The transaction is checked before dispatch and goes through the existing CAS and autosave path. Modal text is not a document revision until Apply; cancel discards it.
## Persistence and compatibility
Additive nodes in existing version-1 rich envelope: inlineEquation {latex}; displayEquation {latex,numbered:boolean}. Atomic leaf nodes, no child content/marks/text, no forged number. Preserve exact original Markdown, document IDs, previous snapshots, layouts, conflict archives, and portable backup hashes. Equations included in search and recovery text. Old clients that do not understand equation nodes reject the new records rather than dropping them. Any future live rollout requires coordinated client and SQL upgrade before enabling account sync. Source-only SQL proposal o5-1-equations.sql replaces the closed node and grammar validators after O4.6; no hosted change. Server validates bounded source and shape, not mathematical semantics or every KaTeX grammar rule.
## Rendering and export
Pinned KaTeX 0.19.1 and transitive commander 15.1.0; lock entries with integrity from homebridge/plugins latest package-lock blob a985cc45dc85404b444f7d85a3023677ba3d5492, verified by npm ci in CI. Bundled in existing lazy editor, output mathml (browser native; no CDN fonts/scripts or runtime external requests). Strict parse, trust false, fresh macros per render, expansion 200 and maxSize 20, 2048 UTF-8 bytes per formula and 128 formulas per snapshot. Reject explicit macro definitions, external-resource/HTML commands, TeX IO commands and manual equation tags/labels. This is a bounded subset of LaTeX math, not arbitrary TeX execution. Unsupported but structurally valid imported formulas retain source with visible rendering error for repair, rather than silently disappearing.
Structured JSON is the lossless document exchange; portable backups include equations and retained history. Original Markdown export remains original. Equation-source inventory is a separate Markdown file with raw LaTeX fragments and derived numbering, not a compilable full LaTeX document. Browser print includes rendered equations and numbers. Physical PDF typography, very long formula wrapping, full LaTeX/DOCX export, citations, cross-references, theorem environments and collaborative math editing remain future work.
