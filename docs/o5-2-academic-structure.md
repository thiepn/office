# O5.2 Academic document structure
Base: main 34524914a486be0d1a509ffd007519826229323c, 217/217 post-merge qualification. No live activation.
## Model and editing
Top-level academicBlock nodes contain a paragraph-first editable rich body. Six kinds: definition, theorem, lemma, proposition, corollary, proof. One document-wide counter shared by the first five kinds; proofs unnumbered with QED presentation. Every block has a generated UUIDv4 and editable unique case-sensitive ASCII label (1–64 characters). References are atomic inline academicReference nodes with targetId, not a stored label or number. Display caption derived in document order; missing target remains explicitly unresolved and editable. No automatic retargeting. Cross-reference picker targets academic blocks only, not equations or headings. Double-click resolved reference to navigate. Insert creates a new top-level block after current root child; edit changes kind/label without replacing body or identity. Undo/redo remains editor transactions. Nested academic blocks intentionally disallowed. Equation nodes permitted in academic bodies. Plain text paste remains unchanged; no external HTML import.
## Persistence and security
Additive version-1 rich nodes. Strict IDs, unique labels and IDs, paragraph-first grammar, no forged number, no arbitrary markup, references in paragraph/heading only. Limits 256 blocks and 1024 references per snapshot. Client validators and source-only SQL proposal after O5.1 enforce constraints. Missing targets allowed deliberately to preserve data across deletion. Labels and captions rendered as text, no HTML or external URLs. Original Markdown, CAS revision history, structured JSON, portable backups and sync preserved. Older clients reject unknown structured nodes; coordinated upgrade required before cloud enable. Browser print retains captions and references; full LaTeX publication export remains future work. No new dependencies.
