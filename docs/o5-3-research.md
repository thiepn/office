# O5.3 Research and citations
Base main e4f81434e7598b78fe1f147c977e006104a0a5e7, 243/243 post-merge checks. Document-local sources in one top-level atomic researchCatalog with immutable UUIDv4 per source and editable unique BibTeX key; inline researchCitation stores only sourceId. First-use numeric order; repeated source shares a number; missing source visibly unresolved and repairable through Edit citation; uncited records remain stored and exported but excluded from generated bibliography. Catalogue is appended on first save/import; remove with explicit confirmation, catalogue deletion via editor also leaves unresolved citations. Manual metadata editing, BibTeX paste or local file import with review and atomic apply, .bib export of all entries. The supported subset is literal brace/quoted/numeric values, 11 named entry types, 25 enumerated fields, no macros, directives, concatenation, unsupported fields or duplicate keys. Values preserve literal braces and TeX markup; bibliography displays plain text, never executes TeX, interprets HTML or opens external links. Review untrusted TeX fragments before compiling elsewhere. Numeric style is a simple in-house format, not full CSL/APA/Chicago. No source fetching, DOI resolution, global library or external services.
